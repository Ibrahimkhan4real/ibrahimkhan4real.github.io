How I work

A reproducible research loop

01

Frame the decision

Start with the operational question, constraints and evidence needed to make a useful claim.

02

Build the comparison

Define baselines, controlled changes and evaluation conditions before interpreting results.

03

Make runs auditable

Use explicit configuration, structured outputs and checks that make experimental runs easier to reproduce.

04

Explain the evidence

Separate what was measured from what is inferred, then communicate the result at the reader’s level.
